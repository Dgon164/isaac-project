# The Theory — A Latent Theory of Informational Structure

**Part 3 of 4.** The conceptual framework, **independent of the machine.** It would
be true whether or not Isaac were ever built. (The machine that bets on it is
`../2_the_machine/`; the evidence that tests the bet is `../2_the_machine/evidence/`
— deliberately *not* here, so the theory stays the theory and not a pile of claims.)

## The keystone

**`Latent_Theory_of_Informational_Structure.docx`** — the single consolidated
derivation, in twelve parts: persistence → comparison → the D0–D6 dimensional
hierarchy → the nine information claims → topological information theory →
puzzle-piece theory → the architecture → the eighteen rules → empirical findings →
holonic processing → the creation loop → the empirical program. *Everything in
`sources/` is one part of this expanded.* It is "unified" but intentionally
**incomplete** — it holds everything currently known and is updated only when the
understanding itself moves, which is rarely.

> Naming note: this file was titled *The Unified Theory of Structural Intelligence*
> (May 2026). The framework's name is now **A Latent Theory of Informational
> Structure** — "latent" because the structure is *objectively there, latent in the
> relationships, and revealed (not invented) by comparison*; "informational
> structure" rather than "structural intelligence" because the theory is about
> information, while *intelligence* is the machine. The builder's own name for it is
> **Intellon theory** (intelligent-holon); "Latent Theory of Informational
> Structure" is the outward-facing name for readers who don't yet know that term.
> *(The .docx's internal title page still reads the old name — a content edit for a
> future pass, not done here.)*
